# TellerGate website

The public website and live demo for TellerGate. The demo runs the real
TellerGate gateway, compiled to WebAssembly, in your browser in front of a
mock bank. All demo data is fictional.

Built from `site/` in the TellerGate repository with `site/build.sh`.
