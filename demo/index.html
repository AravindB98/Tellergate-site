The real TellerGate gateway, compiled to WebAssembly, running in this tab in front of a mock bank. Every decision below comes from the same Go code as make demo. Nothing leaves your browser.

Loading the gateway…

A treasury AI assistant reads the bank's mailbox. One email carries a prompt injection telling it to wire 48,500 to the attacker, with the word "ignore" hidden behind a zero-width space to beat keyword filters. The assistant is scripted to obey, the worst case for any model. Run the scenes in order.

    Send your own calls to the gateway. Agent calls go over MCP as treasury-assistant; people use the admin API with their own tokens. The panel on the right keeps the bank, the session and the approval queue up to date.

    Every decision, observation, approval and halt is appended to audit.jsonl by TellerGate's audit package. Each record holds a SHA-256 hash chained to the previous one and an Ed25519 signature over it. This tab's key pair was generated in your browser when the gateway started.
